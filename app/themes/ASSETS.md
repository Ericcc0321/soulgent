# Asset provenance

Where the art files under `app/themes/` and `app/brand/` came from.

## Seaview theme (`app/themes/seaview/assets/`)

| Path | How it was made | License |
| --- | --- | --- |
| `night_base.png`, `night_screens.png`, `night_leds.png` | Room renders (base, screens lit, LEDs lit) produced in Blender with the project's own scene script; the scene is built from code with flat-colour materials and no imported models, textures or HDRIs. | MIT (this repository) |
| `A.mov`, `B.mov`, `C.mov`, `orca.json` | Orca clips (leap and catch, leap and miss, charge up the beach) rendered in Blender with the project's own script on top of the same scene; encoded to transparent HEVC with ffmpeg. The orca, gull and splashes are modelled in the script. | MIT (this repository) |
| `outdoor_loop.mov`, `outdoor.json` | 12-second seamless sea loop (periodic wave surface, curved beach, shells) rendered in Blender with the project's own script; `outdoor.json` is the sprite and walker data exported by the same pipeline. | MIT (this repository) |
| `points.json` | Seat, queue and path coordinates exported by the Blender scene script. | MIT (this repository) |
| `desks/` (per-desk layers, `*_screen` and `*_led` variants, `desk-layers.json`) | Each desk rendered on its own in Blender (rest of the scene held out) and cropped with the project's scripts for the four islands (Web, Ops, AI, Home). | MIT (this repository) |
| `sprites/gull_tern_*`, `gull_herring_*`, `gull_blackhead_*`, `gullstand_*` | Gull flight and standing frames rendered in Blender with the project's own scripts, using gull models built in the scene script. | MIT (this repository) |
| `sprites/crab_*` (cute, ghost, hermit), sandpiper, turtle and clam frames | Rendered in Blender with the project's own scripts, using animals modelled in those scripts. | MIT (this repository) |

## Brand (`app/brand/soulgent/`)

| Path | How it was made | License |
| --- | --- | --- |
| `app-icon-macos-1024.png`, `Soulgent.icns` | The Soulgent flame mascot (plush look) rendered in Blender, then centred on a dark gradient square with a Python (Pillow) script; `make-icns.sh` builds the `.icns` from the PNG. | MIT (this repository) |
| `flame-mono.svg`, `flame-mono.pdf` (menu-bar icon) | Flame drawn as vector Bezier paths by a project script; `make-menubar-pdf.swift` crops it into the PDF. | MIT (this repository) |
| `pet/soulflame/` (built-in pet) | Spritesheet generated by a Python script from the project's flat flame SVG (translate, tilt and squash per frame); `pet.json` is hand-written. | MIT (this repository) |

All of the art above was generated by this project's own scripts (Blender, Python and ffmpeg), and those scripts were written with Claude Code and Codex. No downloaded models, textures, HDRIs, fonts or ready-made artwork were used. Licence: MIT (this repository).
