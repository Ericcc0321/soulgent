# Contributing

Thanks for taking a look. Soulgent is a one-person hobby project, so issues and small, focused pull requests work best.

- **Bugs:** open an issue with your macOS version, what you expected, what happened, and the relevant lines from `~/Library/Application Support/Soulgent/` logs if there are any. Logs can contain your session names, project paths and macOS user name, so replace those with placeholders before you paste; if you cannot share it without them, use the private channel in [SECURITY.md](SECURITY.md). For anything security-related, see [SECURITY.md](SECURITY.md) instead.
- **Ideas:** open an issue first, so we can agree on the shape before you spend time on code.
- **Pull requests:** keep each one to a single change, and run the tests listed under Development in the README before you send it.
- **Characters:** Soulgent ships no characters besides the Soulgent flame. Add yours on [Petdex](https://petdex.dev), not here.

By contributing you agree that your work is released under the [MIT License](LICENSE).
