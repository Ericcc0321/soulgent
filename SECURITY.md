# Security

Soulgent App can send text into your Claude Code sessions, so treat its admin key like access to your Mac's terminal. The [security model](webapp/README.md) explains what each key can do.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private reporting instead: the **Security** tab of this repository > **Report a vulnerability**. I will reply as soon as I can; this is a one-person hobby project, so please allow a few days.
